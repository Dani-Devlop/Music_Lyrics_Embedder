# Music_Lyrics_Embedder (v2 — main.py)
# Deliberately minimal: the scraper-library stack (syncedlyrics, music-tag,
# beautifulsoup4, RapidFuzz) was removed on purpose so nothing can break from
# an external "library" side anymore.
#   - Lyrics  : LRCLIB over plain HTTP  (requests)
#   - Metadata: Deezer / iTunes Search  (requests)
#   - Tagging : mutagen (ID3 USLT / Vorbis lyrics comment)
#
# Install:
#   python -m pip install -r requirements.txt
